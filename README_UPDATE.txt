L_OS GitHub update pack — icons + app

UPLOAD TO REPO ROOT (same place as current index.html):

  index.html                 ← replace existing
  manifest.webmanifest       ← new
  icons/                     ← new folder (all PNGs inside)
    apple-touch-icon.png
    icon-192.png
    icon-512.png
    icon-maskable-512.png
    icon-1024.png
  L_OS_TUTORIAL_*.html       ← keep / re-upload if missing
  tutorial/audio/*.mp3       ← keep if already there

AFTER UPLOAD:
1. Wait 1–2 minutes for Pages to rebuild
2. iPhone: DELETE the old black Home Screen icon
3. Open Safari → https://YOUR.github.io/REPO/
4. Share → Add to Home Screen (name: L_OS)
5. New icon = burgundy shield with gold T

iOS caches icons hard — you must remove the old shortcut and re-add.
